# GoldenBrush by Sumita

A responsive makeup artist portfolio and booking website built with Next.js, React, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Portfolio photos

Place images in `public/images/`. Add each portfolio image to `PORTFOLIO_ITEMS` in `src/data/siteData.ts` with its title and category. Supported categories include Bridal, Party, Engagement, Traditional, and Model.

## Production

```bash
npm run build
npm start
```
