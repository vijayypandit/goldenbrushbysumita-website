# Image Assets Guide

Place your real photos in this folder (`public/images/`) with the exact filenames below.
The website checks for these files and gracefully displays an editorial placeholder frame if a file isn't added yet.

| Filename | Where Used | Recommended Aspect Ratio |
| :--- | :--- | :--- |
| `hero-portrait.jpg` | Hero section (right side) | 4:5 or 3:4 portrait |
| `about-portrait.jpg` | About Sumita section | 4:5 portrait |
| `portfolio-1.jpg` | Portfolio & Instagram Grid | 1:1 or 4:5 |
| `portfolio-2.jpg` | Portfolio & Instagram Grid | 1:1 or 4:5 |
| `portfolio-3.jpg` | Portfolio & Instagram Grid | 1:1 or 4:5 |
| `portfolio-4.jpg` | Portfolio & Instagram Grid | 1:1 or 4:5 |

| `portfolio-6.jpg` | Portfolio & Instagram Grid | 1:1 or 4:5 |
